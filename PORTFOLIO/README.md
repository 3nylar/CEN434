# CEN434 Project 1 – Personal Portfolio Website

This project is the **first project for my CEN434 class**. It is a personal portfolio website created to practice and demonstrate basic front-end web development skills, including layout design, responsiveness, and simple interactivity.

The website showcases my projects, activities, and basic personal information in a clean and organized way. It was built with simplicity in mind while still following modern web design principles.

## 7. Customization

### Changing Colors
Colors can be updated in the CSS file:
```css
nav {
    background: linear-gradient(135deg, #your-color-1, #your-color-2);
}
```

### Adding New Projects
```html
<div class="projectContainer">
    <img src="images/your-image.jpg" alt="Project image" class="project-picture">
    <h3>Project Title</h3>
    <p>Project description</p>
</div>
```

### Updating Content
Edit the text inside the `<header>` and `About` sections in the HTML file.
