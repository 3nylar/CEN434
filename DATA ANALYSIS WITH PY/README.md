## 4. Working with CSV Files

Most of the datasets used in this topic were stored in **CSV (`.csv`) format**. These files were loaded into Python using Pandas for analysis.

Example:
```python
import pandas as pd

data = pd.read_csv('data.csv')
print(data.head())
```
