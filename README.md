## 5. Topics Covered

### Web Programming
In this part of the course, I learned how to build simple and responsive web pages using:
- HTML for structuring content  
- CSS for styling and layout  
- JavaScript for adding interactivity

### Data Analysis Using Python
I was introduced to data analysis using Python libraries, including:
- NumPy for numerical computations  
- Pandas for data manipulation  
- Matplotlib for data visualization

### Database Programming
This section covered the basics of databases, including:
- SQL and relational database concepts  
- Writing basic queries to store and retrieve data

### NoSQL Databases
I learned about NoSQL databases and why they are used. Topics included:
- Definition and purpose of NoSQL  
- Types of NoSQL databases  
- NoSQL data modelling

**MongoDB**
- Basic concepts and document structure  
- Syntax and data types

**Redis**
- Key-value data storage  
- Basic syntax and data types

### Mobile Application Development
The course also introduced mobile app development using:
- **React Native** or **Xamarin** for building cross-platform mobile applications
